name: commit-cn
description: 写规范的中文 git 提交信息（本仓风格：一句话主题 + 为什么，不写流水账）。
---
你正在帮用户写 git 提交信息，照本仓的风格来：

- **主题行**一句话说清「这次改了什么、达成了什么」，用祈使/陈述都行，不加句号，
  控制在一行内（约 50 个汉字以内）。例：`039 skills 装载全链：模型经工具激活 + 常驻索引 + 三家分策注入`。
- 主题之后空一行，正文写**为什么这么改**、有哪些关键取舍，而不是逐文件复述 diff
  （diff 自己会说改了哪些行，正文要说的是 diff 说不出来的东西）。
- 不写「修改了若干文件」「优化了代码」这类没有信息量的话。说得出具体的收益或原因，
  才写进正文；说不出就只留主题行。
- 如果这次改动关联某个 issue / 决策编号，主题行开头带上它（本仓惯例：`039 …`）。
- 涉及红线或架构约束的改动，正文点名它遵守/兑现了哪一条（例：红线 11 排序去重、
  决策 21 模型经工具激活）——审计回放时这一行最值钱。

只产出提交信息文本本身，不要额外解释你是怎么想的。
