# 152 状态谓词触发 hook（按 150 的拍板实施）← M16 终点

**里程碑** M16 后半 · **依赖** [151](151-derived-registration.md) · **模型** **opus** · **独测** ✅ · **状态** 待做（150 拍板前不动）

## 目标

「当谓词（一条 derived）翻真时，调这个 hook」——扩展自定义时机。
CallTiming 的两个内置时机由此成为通用机制的特例。求值时点、去抖语义、
与 TurnEnd 的关系以 150 的拍板为准。

## 已知的硬约束（不随 150 变）

- **触发不碰 prompt**（决策 21 的判据原文引用）：hook 只能经 command/
  工具面改世界，效果 journaled 可撤可见；直接改组料的路在类型上就不给。
- **稳定态判定**：只在 flushPending 完成后的静止点求谓词，半传播世界对
  hook 不可见。
- **红线 6**：hook 引发的异步回写带 epoch 过闸；undo/取消后迟到的回写
  走既有拒绝路。
- hook 失败只记日志不影响轮结果（136 的既有语义延续）。

## 验收（可判定，随 150 细化）

- 谓词翻真 → hook 恰好按拍板的去抖语义触发；翻假不触发；
- hook 经 command 写状态 → entry 可见、undo 可撤；
- hook 在飞时用户 undo → epoch 闸拒绝迟到回写（红线 6 断言）；
- 触发前后各轮请求体逐字节不受 hook 存在性影响（除 hook 自己经正门
  写入的内容）；
- 不装谓词的会话零变化。
