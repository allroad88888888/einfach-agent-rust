# 151 扩展 derived 注册面（按 150 的拍板实施）

**里程碑** M16 后半 · **依赖** [150](150-derived-extension-decision.md) · **模型** **opus** · **独测** ✅ · **状态** 撤销（2026-08-12）

## 目标

ExtensionPack 能声明 derived 公式：纯派生读挂进原子图，依赖自动追踪、
glitch-free 重算、undo/崩溃恢复后自动与状态一致（derived 不落盘，
重算即一致——这正是卖点）。具体注册面形状以 150 的拍板为准。

## 已知的硬约束（不随 150 变）

- **红线 1**：read fn 纯函数——check-invariants 的扫描面扩到扩展模块
  （时钟/随机/IO 的 grep 面），并在 `docs/EXTENSIONS.md` 写明「公式里
  作弊 = 恢复后静默错值」的完整因果。
- **红线 10**：扩展 derived 的依赖面按可见性裁剪（上下读，禁横读）——
  get 口在图内，天然过既有可见性；断言钉住。
- 256 深度预算对扩展链同样生效；超了走既有 FAULT 帧路径，报错要点得出
  是哪个 pack 的哪条公式。
- **不进快照**：DerivedKey 不 serde 的既有约束原样适用。

## 验收（可判定，随 150 细化）

- pack 声明一条公式 → 依赖的 primitive 变更后重算、无关变更不重算
  （计数器断言）；
- undo/redo/恢复后公式值与重放状态一致（roundtrip 断言）；
- 深度超限 → 可辨认的错误，不 panic 不静默；
- 不带公式的 pack / 不装 pack：逐字节零变化。

## 注意

- opus 依据：红线 1 域——公式不纯不报错，只在恢复后以静默错值浮出来。
- 独测 agent 只看 150 的拍板文 + 本条验收 + 红线 1/10。
