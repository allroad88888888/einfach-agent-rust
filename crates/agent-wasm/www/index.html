Try this — undo that actually removes the turn

Every chat UI has an undo button that deletes a bubble. The model still remembers. Here the whole agent state is one atomic graph with a command log, so undo, redo, crash recovery and audit replay are the same mechanism — not four features.

  1. Say: Remember this passphrase: quokka-88. Just reply OK.
  2. Ask: What is the passphrase? Reply with the passphrase only. — it answers.
  3. Click Undo one turn twice.
  4. Ask: Without using any tools, and based only on our conversation: did I ever tell you a passphrase?

It says no. The turn is genuinely absent from the memory the prompt is rebuilt from — and it stays gone after a refresh, because the undo went to IndexedDB too.

Two more things worth poking at: reversibility barriers — upload an image, ask the agent to describe it (that calls an irreversible tool), then hit undo: it stops and tells you which tool blocked it instead of silently rolling back work that cost money. And the page teaches the agent its own tools — the web: tools listed below are declared and executed by this page; the Rust core knows nothing about them.
