agent-wasm 浏览器宿主

issue 114c 的真机验收页。整个 agent 核心（事件泵、转移表、provider adapter、 IndexedDB 持久化）编成 wasm 跑在这个页面里，没有任何服务端进程—— 这个页面本身由一个静态文件服务器托管，它只发送 .html/.js/.wasm 三种字节，不参与任何一次模型请求。请求由浏览器直接 fetch 到 provider。

key 只来自你自己。这个页面不内置任何 key，也不把你填的 key 存进 localStorage / cookie / 任何地方——它只活在这个标签页的内存里，刷新即失。
